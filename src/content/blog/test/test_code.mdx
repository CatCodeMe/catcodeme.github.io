## 📌 自定义插件

### Focus 插件

使用 `focus={3-5}` 参数或行内 `// [!focus]` 注释，指定行高亮聚焦，其他行淡化：

```js showLineNumbers focus={3-5}
function calculateTotal(items) {
  let total = 0
  for (const item of items) {       // ← 第3行 聚焦
    total += item.price * item.quantity  // ← 第4行 聚焦
  }                                  // ← 第5行 聚焦
  return total
}
```

行内注释方式（`// [!focus]` 会被自动移除）：

```js showLineNumbers
function processData(data) {
  const validated = validateInput(data)
  const transformed = transformData(validated) // [!focus]
  const result = saveToDatabase(transformed) // [!focus]
  return result
}
```

Python 风格（`# [!focus]`）：

```python showLineNumbers
def calculate_fibonacci(n):
    if n <= 1:
        return n
    
    a, b = 0, 1  # [!focus]
    for _ in range(2, n + 1):  # [!focus]
        a, b = b, a + b  # [!focus]
    
    return b
```

### Footnotes 插件

使用 `// [!note:N] 注释内容` 添加代码脚注：

```js showLineNumbers
import express from 'express' // [!note:1] Express Web 框架
import cors from 'cors' // [!note:3] 跨域处理

const app = express() // [!note:2] 创建实例

app.use(cors())
app.use(express.json()) // [!note:4] 解析 JSON

app.listen(3000)
```

自动编号（`// [!note]` 不指定编号）：

```python showLineNumbers
import pandas as pd  # [!note] Pandas 数据分析库
import numpy as np  # [!note] NumPy 数组计算

df = pd.read_csv('data.csv')  # [!note] 读取 CSV 文件
df['norm'] = df['value'] / df['value'].max()  # [!note] 归一化处理

print(df.head())
```

### 折叠代码块

```js collapse={1-5, 12-14, 21-24} showLineNumbers
// All this boilerplate setup code will be collapsed
import { someBoilerplateEngine } from '@example/some-boilerplate'
import { evenMoreBoilerplate } from '@example/even-more-boilerplate'

const engine = someBoilerplateEngine(evenMoreBoilerplate())

// This part of the code will be visible by default
engine.doSomething(1, 2, 3, calcFn)

function calcFn() {
  // You can have multiple collapsed sections
  const a = 1
  const b = 2
  const c = a + b

  // This will remain visible
  console.log(`Calculation result: ${a} + ${b} = ${c}`)
  return c
}

// All this code until the end of the block will be collapsed again
engine.closeConnection()
engine.freeMemory()
engine.shutdown({ reason: 'End of example boilerplate code' })
```
