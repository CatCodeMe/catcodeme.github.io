# Footnotes 脚注插件

为代码行添加注释说明，效果类似学术论文脚注。

---

## 📖 语法说明

### 手动编号（推荐）

在代码行末尾使用 `// [!note:N] 注释内容`：

| 语言 | 语法 |
|------|------|
| JavaScript / TypeScript | `// [!note:1] 注释内容` |
| Python / Ruby / Shell | `# [!note:1] 注释内容` |

### 自动编号

不指定编号时使用 `// [!note] 内容`，会自动从 1 开始递增。

---

## 1️⃣ 手动编号示例

可以随意指定编号，不需要按顺序：

```js showLineNumbers
import express from 'express' // [!note:1] Express Web 框架
import cors from 'cors' // [!note:3] 跨域处理

const app = express() // [!note:2] 创建实例

app.use(cors())
app.use(express.json()) // [!note:4] 解析 JSON

app.listen(3000)
```

---

## 2️⃣ 自动编号示例

不指定编号时自动递增：

```python showLineNumbers
import pandas as pd  # [!note] Pandas 数据分析库
import numpy as np  # [!note] NumPy 数组计算

df = pd.read_csv('data.csv')  # [!note] 读取 CSV 文件
df['norm'] = df['value'] / df['value'].max()  # [!note] 归一化处理

print(df.head())
```

## 3️⃣ TypeScript 示例

```typescript showLineNumbers
interface User {
  id: string  // [!note:1] UUID 格式
  name: string
  email: string  // [!note:2] 用于登录和通知
  role: 'admin' | 'user'  // [!note:3] 联合类型限制
}

async function getUser(id: string): Promise<User> {
  const res = await fetch(`/api/users/${id}`)  // [!note:4] RESTful API
  return res.json()
}
```

---

## 4️⃣ 无脚注代码块

没有 `[!note]` 标记的代码块不显示脚注区域：

```js showLineNumbers
function add(a, b) {
  return a + b
}
```

---

## 🎨 设计特点

| 特性 | 描述 |
|------|------|
| **Emoji 标记** | 使用 1️⃣2️⃣3️⃣ Emoji 数字 |
| **行内显示** | 标记紧跟代码末尾 |
| **手动编号** | `[!note:N]` 可指定任意编号 |
| **自动编号** | `[!note]` 自动递增 |
| **去重排序** | 脚注区域按编号排序 |
| **悬浮提示** | 鼠标悬浮显示完整注释 |
