## Giscus Comment System

<Aside>
  This site uses the Giscus comment system. You can configure it at the
  `integrationConfig.giscus` in file `src/site.config.ts`.
</Aside>

Comments are provided by [Giscus](https://giscus.app/) and stored as GitHub Discussions.

### Setup

Install the [Giscus GitHub App](https://github.com/apps/giscus), enable GitHub Discussions for the repository, then use the [Giscus configuration tool](https://giscus.app/) to obtain the repository and category IDs.

### Configuration

Configure Giscus in `integrationConfig.giscus`.

```ts title="src/site.config.ts"
export const integ: IntegrationUserConfig = {
  // ...
  giscus: {
    enable: true,
    repo: 'owner/repo',
    repoId: 'R_kgDO...',
    category: 'General',
    categoryId: 'DIC_kwDO...',
    mapping: 'pathname',
    theme: 'noborder_light',
    lang: 'zh-CN'
  }
}
```

### Usage

You can call it manually in `.astro` or `.mdx` files.

```jsx
import Comment from '@/components/Comment.astro'

;<Comment />
```

Render:

import Comment from '@/components/Comment.astro'

<Comment />
